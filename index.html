🌍 О Minecraft

Minecraft — это огромный мир, где можно строить, исследовать пещеры, создавать предметы и выживать.



🏰 Разделы моего мира

🌲 Выживание

Базовые предметы и инструменты, которые обязан знать каждый новичок для выживания в первую ночь.

📦 Базовые предметы новичка:

  • 📦 Верстак — главный блок для крафта всех предметов.
  • 🪵 Древесина — самый первый и важный ресурс.
  • ⛏️ Деревянная кирка — нужна, чтобы добыть первый камень.
  • 🔥 Печь — переплавляет руду и готовит еду.
  • 🕯️ Факел — освещает дом и отпугивает мобов.
  • 🛏️ Кровать — пропускает ночь и сохраняет точку спавна.
  • ⚔️ Меч — оружие для защиты от ночных монстров.
  • 🥩 Жареное мясо — восстанавливает сытость персонажа.

💎 Ресурсы и руды

Главные полезные ископаемые, которые нужно научиться искать под землей.

⛏️ Основные руды и их применение:

  • ⬛ Уголь — для крафта факелов и топлива в печи.
  • ⚙️ Железо — для прочной брони, инструментов и ведер.
  • 🪙 Золото — для золотых яблок и торговли с пиглинами.
  • 💎 Алмаз — редкий ресурс для топового снаряжения.
  • 🔴 Редстоун — нужен для создания механизмов и схем.
  • 🔷 Лазурит — используется для зачаровывания вещей.
  • 🟧 Медь — для громоотводов и подзорных труб.
  • 🖤 Незерит — самый крепкий материал в игре из Незера.

👾 Мобы и обитатели

Существа, которых ты встретишь на своем пути — от безобидных животных до опасных монстров.

👹 Важнейшие мобы для новичка:

  • 🧟 Зомби — медленный враг, нападает группами ночью.
  • 💀 Скелет — стреляет из лука с расстояния.
  • 🧨 Крипер — подкрадывается бесшумно и взрывается.
  • 👁️ Эндермен — высокое creature, телепортируется при взгляде.
  • 🕷️ Паук — лазает по стенам, ночью становится агрессивным.
  • 🐄 Корова — дает мясо и кожу для брони/книг.
  • 🐑 Овца — источник шерсти для создания кровати.
  • 🐺 Волк — приручается костью и помогает в бою.
